# 保守契約の編集・締結・解約終了

## 変更対象

`index.html` の既存iframe内にある共通保守契約機能を拡張する。P/Mとも `source.contracts`、固定の内部案件ID・契約ID、親画面経由の `lifecycleTransaction` を利用する。別台帳・別の保存キーは追加しない。

点検・緊急対応記録、設備、案件番号・枝番、案件全体の状態、全社ダッシュボードの分類・稼働判定はこの操作では更新しない。

## 操作

案件詳細の「保守契約・契約更新」で各契約を開く。

- 契約内容を編集：現在値を表示し、同じ契約IDで変更する。締結済みの修正理由は必須。締結状態・締結日・終了予定の変更は編集フォームに混在させない。期間変更が登録済み終了予定と矛盾する場合は保存を拒否する。
- 締結登録：締結日を必須とし、実在日・当日以前を確認する。期間と金額にも既存の検証を適用する。締結の事実を記録し、電子署名や外部送信を実行しない。
- 解約・終了登録：途中解約／契約満了、終了日、理由を必須とする。期間本体とは別の `termination` に終了を記録する。
- 終了予定を変更：未終了の登録済み予定だけを変更できる。修正理由を必須にする。
- 更新契約を新しい記録として登録：新しい契約IDと `previousContractId` を保持し、元の契約・操作履歴を上書きしない。

終了済みの契約は参照専用とし、再開・再締結・再終了を提供しない。終了済み契約からの更新は、旧契約の再開ではなく新規契約レコードの追加になる。

受入済み案件の保守契約番号・金額・締結日・契約状態は他部門でも同じデータを参照する。修正は契約専用フォームへ統一し、一般の入力表や案件の枝番変更登録から契約操作履歴を迂回して変更させない。保守契約以外の契約・他部門業務は維持する。

## 判定と日付境界

契約状況は共通の `maintenanceContractStatus` で判定する。

1. 従来データで明示的に終了なら「終了」。
2. 未締結なら「未締結」。古い終了日があるだけで未締結契約を締結・終了済みにしない。
3. 締結済みで、契約期間末日／登録した終了日のうち早い日を過ぎた場合は「終了」。
4. 締結済みで開始日より前なら「開始前」。それ以外は「契約中」。

終了日当日は有効、翌日から終了。未来の終了登録は基本状態を変えず「終了予定日」を併記する。元の開始・終了日は保持する。途中解約は開始日以降・期間末日以前、満了終了は登録済み期間末日と一致させる。期間不明なら契約内容の編集を案内し、推定で補完しない。

現在契約は「契約中」のものだけを返す。開始前・未締結は一覧で準備中の情報として表示できるが、現在有効とは表示しない。終了した旧契約は引き続き履歴から参照できる。

更新を追加・締結しただけでは旧契約を終了させない。旧契約が終了し、新契約の開始日になった時点で共通の判定により表示を切り替える。期間が重複する場合は確認欄を必須にし、既存の有効契約を維持する。切り替える場合は別の明示的なチェックを必要とし、その選択も監査記録へ保持する。

一覧・詳細・契約フィルター・契約満了／終了予定サマリーは同じ判定を使う。契約終了から案件状態の「終了」や設備・記録の削除を推定しない。自動更新は従来どおり設定の記録のみであり、契約期間の自動延長は行わない。

## 履歴・保存

各契約の `operationHistory` に内部案件ID・契約ID、操作種別、操作日時・利用者、理由、変更前後の契約スナップショット、操作時の状態を保存する。案件の `changeHistory`（枝番履歴）とは別にする。過去の操作は読み取り専用で開く。履歴のない旧契約について、過去の操作日時や担当者を推定して作らない。

契約の更新と履歴追加は共通の一回のブラウザー内保存で確定する。キャンセル・検証エラーでは変更しない。連打は保存中の共通ロックと完了済み操作フラグで防ぐ。保存失敗は契約データ・現在契約選択・履歴をまとめて復元し、入力中のフォームを保持する。開いている間に契約データが変わった場合も保存を拒否する。

関連資料は既存のファイル名を保持して追加する。ファイル本体の保存、サーバー共有、実認証、電子署名・メール等は実装しない。再読み込み後の復元と別タブ競合検知は既存の保存方式を継承する。

## 検証

`python tests/maintenance_contract_operations_smoke.py` でP/Mの同一ID編集、締結、開始前／開始後、途中解約／満了、終了日当日／翌日、予定修正、更新と重複確認、状態の共通参照、保存失敗と再試行、再読み込み、履歴とスマホ表示を確認する。点検・緊急対応および全社分類の関数が置換されていないこと、操作後も案件・設備・記録が維持されることも検証する。
