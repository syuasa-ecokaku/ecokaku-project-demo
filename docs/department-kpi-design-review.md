# 6部門・サマリーKPIカードの共通デザイン

## 開始時・対象範囲

開始点は `fc355f8`、ブランチ `feat/department-notice-cards`。リモートmain `d049134` に対する差分は、前回実装した共通お知らせカードの1コミット。追跡ファイルの未コミット変更・AGENTS.mdはなく、未追跡 `.agents/` は保持する。新しい作業ブランチは `feat/department-kpi-card-design`。前回のお知らせ機能を含めて作業を継続し、mainへのマージ・本番公開は行わない。

実表示は `index.html` の iframe `data-srcdoc` 内。対象は不動産・電力申請・営業・法務・購買・工事のサマリーだけ。メンテナンス、全社トップ、通知、ステータス別件数・予定カード、入力・詳細の表示処理・業務データ・集計は維持する。

参考画像は今回のメッセージに添付されていないため、指示文の寸法・配置・色を基準に実装した。

## 表示処理

- `departmentKpiTokens`：意味ごとのアイコン・色・警告属性を定義。
- `departmentKpiStyleConfig`：6部門の既存KPIキーから意味キーへ明示的に対応付け。項目名の部分一致や表示順で推測しない。
- `departmentKpiIcon`：既存の埋め込みLucide SVGからアイコンを生成。複合表現も同じSVGと線画を利用し、新しい外部通信・CDN・画像は追加しない。
- `departmentKpiDesign`：既存のボタン／参照カード・項目名・数値・補足・クリック属性を保持し、アイコンとレイアウトを追加。対象部門だけに `.dk-*` を付与する。disabledも変更しない。営業・法務の折りたたみ内にある参照KPI8枚も対象とし、非操作のdivをボタン化しない。
- `.dk-*` CSS：白背景、薄い枠、7px角丸、上端3pxアクセント、52pxの丸背景、28pxアイコン、15px項目名、34px数値、小さな単位・補足。アイコンと数値と上端の色を揃える。
- 数値・ラベル・配列・集計ロジックは既存のまま。単位が元からない数値には、元の `strong` の外側に小さく「件」を追加。折りたたみ内の参照KPIは既存の「案件」「件」「万円」をそのまま保持。未設定・対象外・「—」には単位を追加せず、値を0へ変換しない。
- 警告属性のカードが数値0の場合だけ、アイコン・数値・アクセントをグレーにする。ボタンは無効化せず元の操作を維持する。
- 選択状態でも白背景を維持。操作可能なカードだけにホバー・ポインター・フォーカス表示を適用する。装飾SVGは `aria-hidden`。
- 広幅では従来の4～5枚の配列を基本にし、足りなければ折り返す。650px以下は1列。長い値はカード全幅を使い、数値フォントを縮めずに折り返す。

## 検証

同テストで、お知らせカードのHTML、対象外メンテナンスの9画面、全社トップの9表示が開始点と一致することを確認する。既存の通知・イベント・トップ・サマリー・共有データ・部門横断・電力申請のテストも回帰実行する。過去画面のテキスト比較では、今回追加した表示用単位のみを既存の比較補助関数で除外し、数値・ラベル・集計の検査は維持する。
