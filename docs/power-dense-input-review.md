# 蓄電池データ入力：1行化と10件サンプル

## 変更内容

- 実表示される `index.html` の iframe 内を修正。
- データ入力表を1案件1行・1項目1セルへ変更。行高52px、入力欄34px、Meiryo・13px、改行なし。
- 案件番号セルの設備区分、入力欄の「入力済み」等、支払日の参照元説明をセル内から削除。対象外は無効な入力欄に「対象外」と表示し、登録値は保持する。
- 長い申請案件名は省略表示し、titleで全文を表示。参照元は列見出し・値のツールチップとaria-labelへ移動。
- 「詳細」ボタンを右端の独立列に移動。既存の案件詳細への遷移処理を使用し、対応する案件・工程を開く。
- 案件番号・申請案件名の固定2列、固定見出し、横スクロールを維持。固定列の境界を強調。
- 日付欄の内部セグメントに留まらず、Tab／Shift＋Tabで編集可能な次／前のセルへ移動する。参照値・対象外はスキップし、行をまたいで入力できる。端では通常のフォーカス移動を残す。
- 未保存は黄色、入力エラーは赤色、保存済みは白色。保存・取消は非表示の案件・工程の下書きも対象とする従来の動作を維持。

## 共通データと他部門への影響

営業・法務等が使用する既存の `projects` 配列は変更しない。電力申請専用の `powerProjects` カタログに既存3件への参照と追加7件を格納する。

蓄電池のサマリー、データ入力、案件詳細、検索・絞り込み・並べ替え、下書き・保存・取消は、同じ `powerProjects` と従来の案件別保存ストアを参照する。サマリーの管理案件数・工程件数は10件のデータから集計する。既存の工程番号・項目、3事業・3業務タブは維持。

追加案件の共通参照値と工程別サンプル値は、電力申請内の `powerAdditionalSamples`／`powerSampleRecord` に定義。他部門の一覧や売上集計には混入しない。画面内保存のみ・再読み込みで初期化という範囲は従来どおり。実際の送信・外部連携・ファイルアップロードは行わない。
